# Acceptance evidence

This preserves the original 48 acceptance IDs and their criteria in a self-contained public matrix. The original reference package remains unchanged in the local archive and is not required to use this repository. **Verified** means the stated bounded test ran and passed; **Partial** identifies related passing evidence with an untested part of the original criterion; **Deferred** follows the decision to postpone live Lenovo work; **Pending** awaits the specified verification. This matrix does not declare every P0 or external-sharing gate complete.

The matrix records baseline acceptance evidence and retains the scope of each original check. Subsequent connection, event, routing, retention and migration tests extend that baseline; the current twelve-migration suite and release results are recorded in [BUILD_STATUS.md](BUILD_STATUS.md). Unit cases, direct HTTP integration cases, database integration cases and browser observations remain distinct. Earlier operational restore rehearsals covered the then-current schema; disposable dump/restore compatibility now also covers versions 8, 9 and 12. See the [backup procedure](BACKUP.md) for operational recovery checks. Temporary `/tmp` logs are session evidence, not durable repository artifacts; reproducible tests remain in source.
