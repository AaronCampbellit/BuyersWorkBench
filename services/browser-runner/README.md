# Browser runner

The planned private Node.js and TypeScript Playwright service will be implemented after authorized source discovery. No supplier runner starts, accesses Lenovo, or stores supplier sessions in the current build. The registered Go fictional adapter already feeds the common observation/event pipeline; its success is separate from live browser evidence.

The runner will have no database credential, public port, arbitrary URL endpoint, or Docker socket. See the [planned connector boundaries](../../docs/COLLECTION_STRATEGY.md).

Follow the [collection strategy](../../docs/COLLECTION_STRATEGY.md) and complete the [Lenovo discovery record](../../docs/intake/LENOVO_DISCOVERY.md) before selecting browser extraction over a supported API, push feed or export. The approved portal/account, permitted read scope, normal login/MFA and runner isolation remain unresolved.
